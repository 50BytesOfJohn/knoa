App icon

The Tight wordmark shrunk to its first letter and its dot: "K." Each icon is drawn on the macOS 1024 grid (an 824 px rounded tile with room for the shadow) and shown from 128 down to 16 px. Click the big icon to replay it. Download PNG gives you a 1024 px file for Icon Composer.

Icon appearances

Since macOS 26, people can show icons as Default, Dark, Clear or Tinted, so the mark has to survive all four. Click one to put it in the Dock.
